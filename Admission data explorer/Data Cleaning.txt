DATA CLEANING DOCUMENTATION

DATASET INFORMATION

Dataset Name: College Admission Dataset (India)

Source: Kaggle

Original Credit: Kundan Sagar Bedmutha

Dataset Description:

The College Admission Dataset (India) provides a comprehensive representation of the college admission landscape in India. It contains information about students from 26 different Indian states, covering diverse academic backgrounds and career aspirations.

The dataset includes variables related to student demographics, preferred academic streams, entrance examinations such as JEE, NEET, and CET, Class 12 board performance, extracurricular involvement, admission probability, admission status, and scholarship eligibility.

DATA CLEANING PROCESS

Before performing exploratory data analysis and visualization, the dataset was inspected and cleaned to ensure that it was suitable for analysis. The process involved checking the structure of the dataset, missing values, duplicate records, descriptive statistics, data types, inconsistent values, and potential outliers.

First, data.head() was used to display the first five rows of the dataset. This provided an initial view of the data and confirmed that the dataset had been loaded correctly.

Next, data.shape was used to determine the size of the dataset. The dataset contains 25,000 rows and 13 columns.

The data.columns function was then used to identify the variables in the dataset. These include student_id, age, gender, category, state, preferred_stream, entrance_exam, entrance_score, board_percentage, extracurricular_score, admission_probability, admission_status, and scholarship_eligibility.

The data.isnull().sum() function was used to check for missing values. The result showed 0 missing values across all columns, so no missing-value treatment was required.

The data.duplicated().sum() function was used to check for duplicate records. The result was 0, indicating that no duplicate records were found.

The data.describe() function was then used to examine the descriptive statistics of the numerical variables, including their count, mean, standard deviation, minimum, maximum, and quartile values. This helped provide an overview of the numerical data and identify values that required further investigation.

The data.dtypes function was used to check the data types of the variables. The numerical variables were stored as numerical data types, while categorical variables were stored as object/string values. No major data-type issues were identified.

CHECKING FOR INCONSISTENT VALUES

The categorical variables were examined for inconsistent or unexpected values, including differences in spelling, capitalization, or category names. The variables checked included gender, category, state, preferred stream, entrance exam, admission status, and scholarship eligibility.

The values were reviewed to ensure that the categories were consistent and suitable for analysis.

OUTLIER DETECTION

Outliers were investigated using two methods: visual inspection using boxplots and the Interquartile Range (IQR) method.

First, boxplots were created for the numerical variables, including age, entrance score, board percentage, extracurricular score, and admission probability. The boxplots showed potential outliers, particularly in entrance score and admission probability.

The IQR method was then used to statistically identify potential outliers.

IQR = Q3 − Q1

Lower Bound = Q1 − 1.5 × IQR

Upper Bound = Q3 + 1.5 × IQR

For entrance_score, the IQR method identified values above the calculated upper bound as potential outliers. However, the dataset contains different entrance examinations, including CET, JEE, and NEET, which have different scoring ranges. Therefore, these values were investigated rather than automatically removed.

The admission_probability variable also contained some values above its IQR upper bound, which were examined further.

HANDLING OUTLIERS

The identified outliers were not automatically removed because an unusual value does not necessarily represent an error.

The potential entrance score outliers were retained because students took different entrance examinations with different scoring ranges. Removing these values based only on the overall IQR could result in the loss of valid observations.

The identified admission probability values were also examined in the context of the dataset.

Therefore, the outliers were handled based on the context and meaning of the data rather than simply removing every observation identified by the IQR method.

CLEANING SUMMARY

The dataset was inspected for its structure, missing values, duplicate records, descriptive statistics, data types, inconsistent values, and potential outliers. Outliers were first identified visually using boxplots and then statistically using the IQR method. The identified values were investigated before deciding how to handle them.

After the cleaning process, the dataset was prepared for exploratory data analysis, visualization, and development of the Admission Data Explorer.
