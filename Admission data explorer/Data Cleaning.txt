# 4. Outlier Detection

Outliers were investigated using two methods: **visual inspection using boxplots** and the **Interquartile Range (IQR) method**.

## 4.1 Visual Method – Boxplots

Boxplots were created for the numerical variables to identify unusually high or low values.

The variables examined included:

* Age
* Entrance Score
* Board Percentage
* Extracurricular Score
* Admission Probability

The boxplots showed potential outliers in some numerical variables, particularly **entrance score** and **admission probability**. These values were investigated further using the IQR method.

## 4.2 Statistical Method – Interquartile Range (IQR)

The IQR method was used to statistically identify potential outliers.

**IQR = Q3 − Q1**

**Lower Bound = Q1 − 1.5 × IQR**

**Upper Bound = Q3 + 1.5 × IQR**

For `entrance_score`, the IQR method identified values above the calculated upper bound as potential outliers. However, the dataset contains different entrance examinations, including **CET, JEE, and NEET**, which have different scoring ranges.

For this reason, the identified high entrance scores were investigated rather than automatically removed.

The `admission_probability` variable also contained some values above its IQR upper bound, which were similarly examined before deciding how they should be handled.

---

# 5. Handling Outliers

The identified outliers were not automatically removed because an unusual value does not necessarily represent an error.

For `entrance_score`, the potential outliers were retained because students took different entrance examinations with different scoring ranges. Removing them based only on the overall IQR could result in the loss of valid observations.

The identified values in `admission_probability` were also examined in the context of the dataset before making a decision.

Therefore, outlier handling was based on the **context and meaning of the data**, rather than simply removing every observation identified by the IQR method.
