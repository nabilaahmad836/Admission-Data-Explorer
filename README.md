# Admission Data Explorer

## Overview

This project explores a college admission dataset using Python to identify patterns and trends in applicant demographics, program preferences, and admission outcomes. The analysis includes data cleaning, exploratory data analysis (EDA), and data visualization to generate meaningful insights from the dataset.

## Objectives

* Understand the structure of the admission dataset.
* Clean and preprocess the data.
* Check for missing values, duplicates, and inconsistent values.
* Identify and investigate potential outliers.
* Explore admission rates, gender distribution, and program preferences.
* Create visualizations to better understand the findings.
* Generate automated narrative insights from the analysis.

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

1. Imported and inspected the dataset.
2. Examined the dataset structure, columns, and data types.
3. Checked for missing values and duplicate records.
4. Checked for inconsistent categorical values.
5. Identified and investigated potential outliers using boxplots and the IQR method.
6. Performed exploratory data analysis (EDA).
7. Created visualizations for admission rate, gender distribution, and top five programs by demand.
8. Generated automated narrative insights from the findings.
9. Exported a summary report in CSV formats.

## Key Insights

* The overall admission rate was **32.61%**.
* Gender acceptance rates were relatively similar across the categories.
* **Management** had the highest number of applicants among the preferred programs.
* Entrance scores varied depending on the entrance examination taken.
* Potential outliers were investigated and retained where they represented valid observations.
